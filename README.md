个人工作台打造：
子项一：《人生K线》100天极简打卡系统 V1.1
一、核心原则

将《人生K线》设计成一个极简点击式打卡网页。

用户每天不填写时间、不填写分钟数、不填写文字。

用户只需要：

完成一项 → 点击“完成”

没有完成：

不点击。

系统根据用户点击的项目自动计算当天分数。

评分规则、分值、60分及格线、100天规则全部保持不变。

二、每日评分项目

每天固定显示7个项目：

《人生K线》

今日打卡

☐ 07:30前起床          +20分

☐ 23:30前进房间上床    +20分

☐ 今日运动30分钟       +20分

☐ 沉浸式学习1小时以上  +10分

☐ 手机娱乐App <2小时   +10分

☐ 今日完成复盘          +10分

☐ 今日正确执行策略     +10分

每个项目右侧设置一个明显的：

「完成」按钮

点击后：

✓ 已完成     +20

按钮状态发生变化，并且该项目不能重复加分。

三、用户操作方式

每天只需要进行：

打开网页
   ↓
看到7个项目
   ↓
完成一项 → 点击完成
   ↓
继续完成其他项目
   ↓
全部完成后自动计算
   ↓
查看今日得分

例如用户今天：

07:30前起床 ✓
23:30前上床 ✓
运动30分钟 ✓
学习1小时 ✓
娱乐App超过2小时 ✗
完成复盘 ✓
正确执行策略 ✓

系统自动显示：

90分

🟢 今日及格

用户不需要填写任何数字。

四、评分规则

严格按照以下规则：

项目	完成	未完成

23:30前进房间上床	+20	0

手机娱乐App低于2小时	+10	0
今日完成复盘	+10	0
今日正确执行策略	+10	0

总分100分。

60分及格。

评分规则不得修改。

六、今日得分实时变化

用户每点击一次“完成”，分数立即增加。

例如初始：

今日得分

0 / 100

点击起床：

20 / 100

点击上床：

40 / 100

点击运动：

60 / 100

🟢 已及格

点击学习：

70 / 100

这样用户可以非常直观地看到：

我今天已经达到及格线。

七、K线蜡烛图

这是本系统的核心视觉。

不要只使用普通折线图。

将100天每日得分转换为人生K线蜡烛图。

基本逻辑

每一天对应一根K线。

纵轴：

0～100分

横轴：

第1天～第100天

当天最终得分作为当天K线的数据核心。

如果第一版真正标准OHLC K线实现较复杂，可以采用“单日分数蜡烛柱”：

100 ┤
 90 ┤       █
 80 ┤   █   █
 70 ┤   █   █
 60 ┼──────────── 60分及格线
 50 ┤ █
 40 ┤ █
 30 ┤
 20 ┤
 10 ┤
  0 ┤
    └──────────────
      1  2  3  4 ...

重点是让用户能够一眼看到：

我的人生K线是在向上、横盘还是向下。

八、K线颜色逻辑

颜色只用于表达当天是否及格：

≥60分

使用“上涨/及格”视觉。

<60分

使用“下跌/不及格”视觉。

60分设置为水平及格线。

让用户一眼能够看到：

最近10天，我的K线大部分是在60分上方还是下方。

十二、不要增加任何复杂输入

第一版禁止要求用户填写：

起床具体时间
睡觉具体时间
运动分钟数
学习分钟数
手机使用时长
复盘文字
股票交易内容
心情
备注

这些全部不需要。

用户自己判断是否满足标准，然后点击：

完成

系统只负责记录。

十三、特别重要：每天只能打卡一次

每天的7项完成状态需要保存。

当天已经点击“完成”的项目：

不允许重复点击。

当天已经完成的项目显示：

✓ 已完成

未完成项目保持：

○ 完成

当天结束后形成最终分数。

第二天自动生成新的7项打卡。

十四、最终产品理念

整个产品必须保持一个核心：

少输入、少思考、强反馈。

用户每天只做一件事：

完成了，就点一下。

然后系统告诉用户：

今天的人生K线收在多少分。

最终形成：

生活
 ↓
行动
 ↓
点击打卡
 ↓
自动评分
 ↓
每日K线
 ↓
100天趋势
 ↓
看到自己的生活是否真正向上

不要把它做成复杂的习惯管理软件。

它本质上是：

《人生K线》——人生每日收盘系统

第一版只解决一个问题：

让我每天知道：今天的自己，到底有没有比昨天更好。
